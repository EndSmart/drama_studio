# Scriptwriter — 剧本生成

> 被 `script-agent` 加载，指导 Stage 2 剧本生成。详细执行逻辑见 `../../agents/script-agent.md`。

---

## 剧本格式规范

短剧剧本采用标准影视剧本格式，每场景包含以下要素：

| 要素 | 格式 | 说明 |
|------|------|------|
| 场景编号 | `## Scene {N}` | 从 1 开始递增，全剧连续编号 |
| 地点 | `**地点**: {具体地点}` | 如「总裁办公室」「校园操场」 |
| 时间 | `**时间**: {日/夜/傍晚/清晨}` | 一天中的时段，仅使用四个标准值 |
| 人物 | `**人物**: {角色名1}、{角色名2}...` | 本场景出场角色，顿号分隔 |
| 对白 | `{角色名}: {台词内容}` | 每条对白独立一行 |
| 动作/表情 | `({动作或表情描述})` | 括号包裹，放在对白前或独立成行 |

---

## 场景拆分原则

每集 3-5 个场景，每场景约 3-5 个镜头量（预估）。

| 拆分规则 | 说明 |
|----------|------|
| 场景 = 同一地点 + 同一时段 | 地点或时间变化即新场景 |
| 每集 3-5 个场景 | 含开场 hook 场景和结尾悬念场景 |
| 场景内镜头量 3-5 | 为 S3 分镜预留合理的拆分空间 |
| 对白为主场景 ≤ 5 个镜头 | 对白密集的场景不宜过长 |
| 动作为主场景 ≤ 3 个镜头 | 动作场景以视觉冲击为主，保持节奏 |

---

## 对白编写规范

对白是短剧的核心表达方式，必须满足以下规范：

1. **口语化**：用日常说话方式编写，避免书面语、文绉绉的表达
   - 正例：「你怎么在这？」
   - 反例：「请问你为何会出现在此地？」
2. **符合角色性格**：对白风格与角色 personality 设定一致
   - 霸总：简短、命令式、略带冷淡
   - 甜宠女主：温柔、含蓄、偶尔俏皮
   - 搞笑配角：夸张、跳跃、口语化
3. **每句不超过 20 字**：短剧对白要求简洁有力
   - 超过 20 字时拆分为两句，中间插入动作指示
4. **信息密度高**：每句对白推动情节或展现性格，避免废话
5. **对话交替自然**：双人对白用正反打节奏（A → B → A → B），每方连续说话不超过 2 句

## 时长分配策略

每集按以下策略分配时长（以每集 120 秒为例）：

| 段落 | 时长 | 占比 | 说明 |
|------|------|------|------|
| 开场 hook | 10s | 8% | 快速抓住观众注意力，抛出悬念或冲突 |
| 情节推进 A | 44s | 40% | 第一段情节展开，建立场景和人物关系 |
| 情节推进 B / 转折 | 38s | 35% | 冲突升级或关键转折点 |
| 悬念 / 转折高潮 | 18s | 17% | 本集冲突最高点或转折 |
| 下集预告钩子 | 10s | — | 结尾悬念，引导观众继续观看 |

场景时长估算公式：`对白行数 × 3s + 动作指示数 × 2s`

```markdown
...
```

## 纪律约束

1. **只做剧本生成**：不涉及分镜设计、镜头语言标注、视频制作
2. **忠实于故事**：不擅自添加角色、改变主线情节、修改结局类型
3. **格式严格**：场景编号连续，时间标注统一（仅用日/夜/傍晚/清晨），对白格式一致
4. **时长意识**：每集场景总时长估算不超过 `duration_per_episode` + 10%
5. **产物是中间态**：剧本 Markdown 仅供 storyboard-agent 消费
6. **幂等性**：若 `script_path` 已存在且有效，跳过生成直接返回
