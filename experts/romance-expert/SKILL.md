# 言情短剧专家 (Romance Expert)

## 类型特色

- 情感驱动：以人物间的情感关系为叙事核心，所有情节服务于情感线的推进
- 每集有情感冲突和解决：单集内完成一个小情感弧线，同时推进整体关系线
- 节奏密集：每集 1-2 分钟，情绪起伏高频，避免长时间无冲突铺垫
- 视觉优先：用动作、表情、场景细节传达情感，减少大段旁白
- 代入感强：角色设定贴近目标受众的心理投射，强化代入与共鸣

## 故事结构模板

```
相遇 → 误会 → 靠近 → 阻碍 → 表白/反转 → HE/BE
```

### 结构说明

1. **相遇**（第 1-2 集）：男女主角初次相遇，制造印象深刻的初见场景。设定身份差异或命运交集，埋下情感种子
2. **误会**（第 3-4 集）：因身份、言语或第三方产生误会，制造初次冲突。误会需合理，不可靠强行降智推动
3. **靠近**（第 5-8 集）：在互动中逐渐了解对方，情感升温。设计名场面（同居、合作、意外接触）加速关系推进
4. **阻碍**（第 9-12 集）：外部阻力（家庭、阶级、前任、事业）或内部阻力（心结、恐惧、承诺）阻挡关系发展
5. **表白/反转**（第 13-15 集）：核心情感爆发点。真相揭露、心意传达、关键抉择，推向情感高潮
6. **HE/BE**（第 16-20 集）：甜宠走向 HE（Happy Ending），虐恋走向 BE（Bad Ending）或先虐后甜的 HE

## 角色原型

| 原型 | 特征 | 功能 |
|------|------|------|
| 霸总 | 高冷/强势/占有欲强/隐藏软肋 | 制造权力差与反差萌 |
| 暖男 | 温柔/体贴/守护型/默默付出 | 提供情感安全感与三角张力 |
| 灰姑娘 | 普通出身/善良坚韧/不卑不亢 | 观众代入入口，制造阶级冲突 |
| 白月光 | 完美/逝去/无法替代 | 制造心结与情感障碍 |
| 绿茶 | 伪装善良/暗中挑拨/表里不一 | 制造误会与外部冲突 |
| 青梅竹马 | 久别重逢/熟悉感/暗藏情愫 | 提供情感铺垫与遗憾张力 |

## 情节套路

1. **契约婚姻**：因利益或不得已签订婚姻契约，在假扮夫妻中弄假成真
2. **失忆重逢**：一方失忆后重逢，另一方以新身份重新接近，真相揭露引发情感危机
3. **替身情人**：因酷似白月光被选中，在替身身份中挣扎，最终证明自身独特价值
4. **误会分手**：因第三者挑拨或信息差导致分手，真相大白后追妻/追夫火葬场
5. **双向暗恋**：双方互相暗恋却误以为对方不喜欢自己，通过一系列事件捅破窗户纸

## 结局偏好

- **默认 HE**：甜宠、双向奔赴类以 Happy Ending 为主
- **虐恋可 BE**：若整体基调为虐恋且用户指定，可使用 Bad Ending，但需留有余韵和美感
- **先虐后甜**：虐恋线最终走向 HE 时，虐的部分需有情感回报，不可为虐而虐

## 每集节奏

```
3秒 hook（情绪冲击/名场面切入）
→ 情感升温（互动/对话/细节）
→ 误会/冲突（外部介入或内心挣扎）
→ 悬念结尾（未解决的冲突/新信息/情感抉择）
```

### 节奏要点

- **3 秒 hook**：每集开头 3 秒内抓住观众，使用强情绪画面（对峙、眼泪、意外亲密、反转台词）
- **情感升温**：中段安排 1-2 个互动场景，推进关系或深化冲突
- **误会/冲突**：每集至少一个冲突点，冲突大小可不同但不可缺席
- **悬念结尾**：结尾留在情感转折点上，让观众产生"下一集会怎样"的冲动
