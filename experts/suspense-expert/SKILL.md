# 悬疑短剧专家 (Suspense Expert)

## 类型特色

- 信息控制：精确管理观众、主角、反派之间的信息差，制造悬念与紧张感
- 反转密集：每 2-3 集安排一次反转，反转需有前期伏笔支撑，不可凭空出现
- 每集结尾留悬念：每集结尾必须抛出新问题或颠覆已知信息，驱动观众追看
- 氛围营造：通过场景、光影、音效描写强化悬疑氛围
- 逻辑严密：所有线索、动机、时间线需经得起推敲，避免逻辑漏洞

## 故事结构模板

```
案件发生 → 初步调查 → 线索误导 → 真相反转 → 结局揭示
```

### 结构说明

1. **案件发生**（第 1-2 集）：以案件/事件开场，迅速建立悬念。交代受害者/失踪者/异常现象，引出调查者
2. **初步调查**（第 3-6 集）：主角展开调查，收集初始线索。引入嫌疑人池（3-5 人），每人有动机和不在场证明
3. **线索误导**（第 7-12 集）：放出误导性线索，指向错误嫌疑人。同时埋下真相关键伏笔（不起眼但合理）
4. **真相反转**（第 13-16 集）：颠覆既有认知，揭示隐藏真相。反转可涉及身份、动机、时间线或叙述者本身
5. **结局揭示**（第 17-20 集）：完整揭露真相，处理动机与人性层面。结局可留有开放性或道德灰度

## 角色原型

| 原型 | 特征 | 功能 |
|------|------|------|
| 侦探 | 敏锐/执着/有缺陷/独到视角 | 调查推进者，视角代入 |
| 嫌疑人 | 各有动机/表面配合/暗藏秘密 | 制造迷雾与推理空间 |
| 受害者 | 死后/失踪后仍影响剧情 | 通过碎片信息驱动故事 |
| 卧底 | 双重身份/内心挣扎/随时暴露 | 制造身份悬念与道德冲突 |
| 心理医生 | 洞察人心/专业冷静/可能有秘密 | 提供心理分析视角，可作反转点 |
| 法医 | 冷静客观/相信证据/发现关键细节 | 提供物证线索，打破僵局 |

## 情节套路

1. **密室杀人**：封闭空间内的不可能犯罪，核心在于破解密室手法与发现隐藏通道/机关
2. **连环案件**：多起案件按某种规律串联，逐步揭示凶手的模式和动机
3. **记忆碎片**：主角或关键证人的记忆不完整/不可靠，通过拼凑碎片逼近真相
4. **双重身份**：关键角色拥有隐藏身份，身份揭露成为核心反转点
5. **不可靠叙述者**：叙述者本身即是参与者/凶手，通过信息选择性呈现误导观众

## 结局偏好

- **OE（Open Ending）**：留有未解之谜或道德灰度，引发观众讨论与回味
- **反转 BE**：真相揭露后主角未能全身而退，或正义付出了沉重代价
- **慎用纯 HE**：若使用 HE，需在前序剧情中付出足够的代价，避免廉价团圆

## 每集节奏

```
悬念 hook（未解问题/新发现切入）
→ 线索发现（推进调查，给出新信息）
→ 误导信息（指向错误方向，制造迷雾）
→ 反转/新悬念（颠覆认知或抛出新问题）
```

### 节奏要点

- **悬念 hook**：每集开头承接上集悬念或以新发现切入，3 秒内建立紧张感
- **线索发现**：中段推进调查，每集至少给出 1 条新线索（真线索或假线索）
- **误导信息**：安排误导性线索或嫌疑人可疑行为，维持推理张力
- **反转/新悬念**：结尾抛出反转或新悬念，让观众产生"凶手到底是谁"的追问冲动
