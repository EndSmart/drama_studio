# 通用短剧专家 (General Drama Expert)

## 类型特色

- 通用叙事结构：提供经典四幕结构，适配爱情、悬疑、喜剧、奇幻、都市、家庭等各种题材
- 灵活适配：不预设类型限制，根据用户主题动态调整角色、情节与结局走向
- 质量保障：通过通用故事质量检查清单确保基础叙事质量
- 兜底覆盖：当用户需求未命中任何 L2 领域专家时，作为默认专家接手创作

## 触发条件

- 未命中 romance-expert（言情关键词）
- 未命中 suspense-expert（悬疑关键词）
- 未命中 comedy-expert（喜剧关键词）
- 用户主题为跨类型、混合类型或无法明确归类

## 故事结构模板

```
起（设定）→ 承（发展）→ 转（冲突/转折）→ 合（解决/结局）
```

### 结构说明

1. **起·设定**（第 1-3 集）：建立世界观、角色关系与初始状态。交代主角背景、核心欲望与现状，埋下后续冲突种子
2. **承·发展**（第 4-10 集）：推进角色行动与关系发展，逐步引入冲突要素。情节在原有设定上自然延伸，加深观众对角色和世界的理解
3. **转·冲突/转折**（第 11-16 集）：核心冲突全面爆发或关键转折出现。颠覆角色现有状态，迫使角色做出重大抉择，推向故事高潮
4. **合·解决/结局**（第 17-20 集）：冲突解决，角色完成弧线，故事收束。结局类型根据主题和用户需求选择 HE/BE/OE

## 角色原型

- 按用户主题灵活创建
- 确保每个主要角色具备：明确的动机、可辨识的特征、清晰的弧线
- 角色数量建议：主角 1-2 人，重要配角 2-4 人，功能性角色按需设置

## 情节套路

- 按主题灵活设计
- 确保情节服务于角色弧线和主题表达
- 避免套用不匹配主题的固定套路

## 结局偏好

- 按主题选择 HE/BE/OE
- HE（Happy Ending）：适合轻松、正向、娱乐导向的主题
- BE（Bad Ending）：适合悲剧、现实、深刻导向的主题
- OE（Open Ending）：适合留有余韵、引发讨论的主题
- 结局需与前序剧情的基调一致，不可突兀转向

## 通用故事质量检查清单

在输出故事大纲前，逐项检查以下质量标准：

- [ ] **角色动机明确**：每个主要角色的行为都有清晰的动机支撑，不存在无理由的行动
- [ ] **冲突有层次**：冲突从表层到核心层层递进，不是单一平面的对抗
- [ ] **结局有逻辑**：结局由前序剧情自然推导而来，不存在机械降神或强行收束
- [ ] **节奏不拖沓**：每集有信息增量，不存在整集无实质推进的情况
- [ ] **伏笔有回收**：前序埋设的伏笔在后续得到回应或回收
- [ ] **角色弧线完整**：主角在故事结束时相比起点有明确变化（成长/堕落/转变）
- [ ] **主题一致性**：所有情节和角色服务于核心主题，无游离的支线
