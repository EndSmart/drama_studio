# 喜剧短剧专家 (Comedy Expert)

## 类型特色

- 节奏快：信息密度高，笑点密集，不拖泥带水，每集 1-2 分钟内完成起承转合
- 反转多：每集至少 1 次预期打破，反转需出人意料又在情理之中
- 金句密集：台词追求短、准、狠，每集留 1-2 句可传播的金句
- 接地气：角色和情境贴近日常生活，观众能即时产生共鸣
- 情绪正向：即使在冲突中也保持轻松基调，不走向沉重

## 故事结构模板

```
日常设定 → 意外事件 → 连锁误会 → 爆笑高潮 → 反转收尾
```

### 结构说明

1. **日常设定**（第 1 集）：建立角色日常与关系，用 1 集快速立住人设。设定需接地气，让观众迅速代入
2. **意外事件**（第 2-5 集）：打破日常的意外事件发生，启动喜剧冲突。事件需荒诞但根源合理
3. **连锁误会**（第 6-12 集）：因意外事件引发一连串误会，误会层层叠加，笑点滚雪球式放大
4. **爆笑高潮**（第 13-16 集）：所有误会集中爆发，形成信息差最大的混乱场面，笑点密度达到顶峰
5. **反转收尾**（第 17-20 集）：真相大白或意外反转，以欢乐方式收束。反转需颠覆前序认知但逻辑自洽

## 角色原型

| 原型 | 特征 | 功能 |
|------|------|------|
| 社畜 | 加班/卑微/吐槽型人格/偶尔反抗 | 观众代入入口，制造职场共鸣 |
| 损友 | 不靠谱/坑队友/但关键时刻顶上 | 制造麻烦与连锁误会的发动机 |
| 奇葩上司 | 迷之自信/外行指导内行/口头禅多 | 制造职场冲突与荒诞感 |
| 戏精 | 夸张/自我加戏/脑补能力强 | 放大误会，制造喜剧效果 |
| 直男 | 不解风情/字面理解/耿直到离谱 | 制造沟通错位笑点 |
| 闺蜜 | 毒舌/热心/出馊主意/八卦 | 提供吐槽视角与推动剧情 |

## 情节套路

1. **职场乌龙**：因信息传达错误或操作失误引发职场闹剧，层层升级直至惊动高层
2. **相亲闹剧**：相亲中出现各种意外（认错人、前任出现、奇葩对象），制造社死与笑点
3. **朋友坑友**：损友的好心帮忙反而帮倒忙，连锁反应越搞越大，最终自己收拾烂摊子
4. **身份错位**：因误会或被迫扮演不属于自己的身份，在错位中制造笑料，真相揭露时反转
5. **社死现场**：主角在最不恰当的场合遭遇最尴尬的状况，通过层层补救反而越描越黑

## 结局偏好

- **HE（欢乐收尾）**：所有误会在笑声中化解，角色关系反而因闹剧变得更紧密
- **反转式 HE**：结局来一次预期反转，让观众在笑声中结束
- **避免 BE**：喜剧不走沉重或悲伤结局，即使有代价也以轻松方式呈现

## 每集节奏

```
3秒 hook（笑点切入/名场面开场）
→ 事件升级（意外发生/矛盾加深）
→ 连锁反应（误会叠加/笑点滚雪球）
→ 反转/金句收尾（颠覆预期或一语点睛）
```

### 节奏要点

- **3 秒 hook**：每集以笑点或名场面开场，3 秒内让观众笑出来或产生好奇
- **事件升级**：中段推动事件升级，矛盾越搞越大，笑点层层递进
- **连锁反应**：安排 2-3 个连锁误会，每个误会在前一个基础上叠加放大
- **反转/金句收尾**：结尾用反转打破预期，或用一句金句收束，让观众有传播冲动
